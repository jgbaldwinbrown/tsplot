# TSPlot

## Introduction

TSPlot is a Go language library and set of executables for analyzing and plotting time series allele frequency data.

## Importing

To use this library in a Go program, just import the entire library as follows:

```go
import (
	"github.com/jgbaldwinbrown/tsplot/pkg"
)
```

and it will be available as "tsplot".
